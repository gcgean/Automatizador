// o que é uma requisição?

Cada ação que um sistema externo realiza dentro do AppBarber conta como uma requisição.

Toda vez que um agente externo - seja um chatbot, um dashboard de BI ou um site próprio - precisa buscar ou enviar informações ao sistema, ele faz uma chamada à API. Essa chamada é uma requisição.

→IA no WhatsApp consulta horários disponíveis = 1 requisição
→Dashboard atualiza faturamento do dia = 1 requisição
→Site cria um agendamento = 1 requisição
// requisitos técnicos

O que é necessário para contratar

Leia antes de solicitar. Esses requisitos existem para garantir a segurança dos dados do seu estabelecimento.

🏢
Ser cliente ativo do AppBarber

A API é um módulo adicional do sistema. Não é possível contratar sem ter uma conta ativa no AppBarber.

📄
CNPJ ativo vinculado à conta

O acesso é liberado exclusivamente para pessoas jurídicas. O contrato é emitido em nome do CNPJ do estabelecimento.

🔒
IP fixo obrigatório

Por segurança, todos os acessos são homologados a endereços de IP estático. Você fornecerá o IP após assinar o contrato.

👤
Solicitação feita pelo gestor

O contrato é gerado e enviado ao gestor titular da conta. Desenvolvedores devem orientar o gestor a realizar a solicitação.

Se você já tem uma conta ativa no AppBarber, a contratação da API pode ser feita direto pelo sistema - ou pela nossa equipe, se a área ainda não estiver visível para você.

  • 3Se a área não estiver visível, acione nossa equipe
  • 4Assine o contrato, envie o IP fixo e compre os créditos
